# 视觉参考选择指南

按文字建议需要表达的信息关系选图，不按海报风格选图。普通讲述可保持稳定人物与基础字幕；有自然留白且需短设问时可先看08。只写稿或调整自然说法无需看图。

## 使用步骤

1. 提出具体画面、排版或制作建议时，先找其对应示例，用 `view_image` 或可显示图片的等效工具打开实际图片。文件名和文字摘要不能代替看图。先看一至两种最相近关系；复杂多阶段任务可逐段追加相关图组，不一次加载全库。
2. 区分同级分类、先后步骤、对照、动作关系和证据阅读，不让相似卡片冒充不同语义。若图只匹配规则的一部分，明确该部分，不宣布整条已示范。
3. 结合每例的教学时间、真实内容回放时间和稳定源帧记录，迁移主次、相对位置、避让与阅读区。图片是原创重绘，不是原视频截图或事实证明；人物、文字、数字及产品均不得搬作用户事实。
4. 用户要动态方案时另读该例源序列，或打开配套状态图。稳定图和状态对照不能证明中间轨迹、速度、声音或用户新作已达标。画面相继出现不能误说同时常驻。
5. 替换为当前获准人物和有据文案，按实际画幅重新排版，不机械套用像素、主体占比、颜色或字体。图内必须是具体内容，不用“重点词/主体卡/标题区”等排版标签代替口播内容。
6. 渲染后实际打开复核；逐字核对正文、基础字幕和卡片，尤其数字、单位、条件与否定。文字错误必须修正图片，不能靠说明补救。动态另查入场/中途/落位和可读停留。

打不开图时说明未检视，只给文字层面建议。没有真正匹配的参考时不能把无关图挂作已覆盖，应明确缺口并重新寻找或设计。

以下资产按实际比例等比导出：普通构图短边480，密集文字或地图短边720；原始大图不随Skill分发。尺寸不是新作输出规格，最终仍按用户平台检查可读性。
